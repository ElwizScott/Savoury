# 🍳 Savoury – Smart Cooking App

[![Swift](https://img.shields.io/badge/Language-Swift-orange?logo=swift&logoColor=white)](https://swift.org/)  
[![SwiftUI](https://img.shields.io/badge/Framework-SwiftUI-blue?logo=swift&logoColor=white)](https://developer.apple.com/xcode/swiftui/)  
[![Core ML](https://img.shields.io/badge/AI-Core%20ML-green?logo=apple&logoColor=white)](https://developer.apple.com/machine-learning/)  

Savoury is an **iOS application** that helps users discover recipes by scanning ingredients or selecting dietary preferences.  
It combines **Core ML image recognition** with a clean **SwiftUI interface**, making cooking more accessible, fun, and personalized.  

---

## 🚀 Features
- 🔐 **Sign In / Authentication** (basic app entry)  
- 🏠 **Home View** with curated dishes of the day  
- 🥦 **Ingredients Search** – find recipes by scanning or selecting items  
- 📖 **Recipe View** – detailed cooking steps, nutrition, and serving info  
- ⚙️ **Culinary Preferences** – set dietary needs (vegan, gluten-free, etc.)  
- ⏲️ **Timer View** – built-in cooking timer for recipe steps  

---

## 🛠️ Tech Stack
- **Language:** Swift  
- **Frameworks:** SwiftUI, Core ML  
- **Design:** Figma, Apple HIG (Human Interface Guidelines)  
- **IDE:** Xcode  
- **Data:** Recipe APIs + local SwiftData for storage
